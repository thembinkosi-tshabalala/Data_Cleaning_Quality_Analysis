Data Cleaning & Quality Analysis
Project Overview
This project demonstrates an Excel-based data cleaning and quality analysis workflow using a 30-record inventory dataset.
The project focuses on identifying data quality issues, validating records, calculating key metrics, and presenting the results through summary tables and charts.
Objectives

Identify missing and incomplete data
Check for duplicate customer IDs
Validate customer and order information
Calculate inventory and procurement metrics
Analyse product performance
Analyse regional quantities and procurement values
Present findings using Excel charts and summary tables

Data Quality Checks
The dataset was checked for:

Missing Customer IDs
Duplicate Customer IDs
Missing Names
Missing Regions
Missing Products
Missing Order Dates
Missing Quantities
Missing Unit Prices
Missing Email Addresses

The analysis identified 2 records requiring review: one record with a missing quantity and one with a missing email address.
Key Results

Total Records: 30
Total Quantity: 106
Total Procurement Value: 250,950
Average Unit Price: 4,165.00
Records Needing Review: 2
